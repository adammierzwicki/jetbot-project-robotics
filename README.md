# Jetbot self driving project

## Install jetbot dependencies
Installing dependencies:

```bash
sudo python3 setup.py install
```

## Our steering code

Our main steering logic for manual driving is in `notebooks/teleoperation/teleoperation.ipynb`

Models for autonomous driving and Python scripts for inference are in `notebooks/driver_model/`

Best script is `live_demo_gray.py`.
